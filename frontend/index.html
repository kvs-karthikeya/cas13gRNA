How scoring works

Score = 1 − { [a × (−1)] + [(28 − b) × (−0.5)] }  =  1 + a + 0.5 × (28 − b)

a is the number of bases in the guide's target window that pair in the predicted structure (double-stranded). b is the spacer length. Lower is better; 1 is the best possible score.

Examples: a 28 nt guide with 0 paired bases scores 1. With 3 paired bases it scores 4. A 23 nt CasRx guide with 0 paired bases scores 3.5.

Seed rule: the central seed (positions 11–18, or 1–6 for CasRx) must be single-stranded. Guides that fail it are not shown.
